# Overview

A basic web application that displays "Hello World" to anyone who visits it.

# Personas

- Visitor — views the hello world message in their browser.

# Features

- A visitor opens the application in their web browser.
- The page displays "Hello World" as text.
- The application runs on a web server accessible via URL.
- The page loads quickly when accessed.
- The display works across common browsers like Chrome, Firefox, and Safari.
